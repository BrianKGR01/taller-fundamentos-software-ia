# Lineamientos visuales y técnicos (para la fase de presentación)

> Este documento reúne las decisiones iniciales de diseño e infraestructura para cuando pasemos a construir la presentación web y desplegarla en Vercel.

## 1. Marca e identidad visual

- **Comunidad:** Google Developer Group (GDG) Santa Cruz.
- **Línea gráfica:** Identidad oficial de Google Developer Groups (colores Google — azul, rojo, amarillo, verde —, tipografía Google Sans / Google Sans Mono cuando corresponda, y uso estricto de logos oficiales GDG sin redibujarlos).
- **Diferenciación obligatoria:** **NO repetir** la estética, layout ni propuesta visual del taller anterior ([`taller-ttw-kevin-gomez`](../../taller-ttw-kevin-gomez/README.md) / `https://taller-ttw-ia-empresas.vercel.app/`).
- **Dirección creativa buscada:**
  - Más **creativa**, más **Google** y más **dinámica**.
  - Enfoque didáctico y visual para personas sin formación técnica: diagramas interactivos, metáforas visuales claras (ej. el mapa del software por capas), transiciones con intención y ritmo fluido entre bloques.

## 2. Funcionalidad y despliegue previstos

- Acceso libre en **Vercel** para proyectar en vivo y compartir con los asistentes.
- Modo presentación + vista navegable/legible desde móvil (para que quienes asistan puedan repasar los conceptos, ejemplos y prompts).
- Control de versiones con **Git** (`brayankgr@gmail.com`) en repositorio público de GitHub (`BrianKGR01/taller-fundamentos-software-ia`).
