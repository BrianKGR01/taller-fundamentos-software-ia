# Taller Fundamentos de Software con IA

**GDG Santa Cruz · Expositor: Kevin Brayan Gómez Rocha**

Material de planificación y futura presentación web del taller **«Fundamentos de Software con IA: qué necesitas saber antes de entrar a Spec-Driven Development»**, pensado para personas **sin formación en programación ni ingeniería de software** que quieren construir productos reales dirigiendo agentes de IA.

## Propósito dentro de la ruta de talleres

1. **Este taller (el antes):** mapa mental completo del software por dentro (UX/UI, frontend, backend, servidores, bases de datos, APIs, autenticación, ciberseguridad, Git y entornos) para saber qué pedir, qué esperar y cómo evaluar el trabajo de la IA sin tocar código.
2. **Siguiente paso — Spec-Driven Development:** [IA aplicada al desarrollo de software: el proceso de desarrollo en la era agéntica](https://taller-ttw-ia-empresas.vercel.app/).
